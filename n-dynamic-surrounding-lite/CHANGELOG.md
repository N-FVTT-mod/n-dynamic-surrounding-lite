# Changelog

## 1.0.0

- Initial standalone Lite clock with an HTML/CSS analog dial, calendar display, and Scene-light indicator.
- Added calendar and Scene-light messages, token vision warnings, and optional emphasis for time jumps.
- Added English and Simplified Chinese localization and a Patreon banner for the full edition.
- Prepared installation, license, third-party, maintenance, and regression documentation for public release.

No previous Lite data migration is required for this initial version.
